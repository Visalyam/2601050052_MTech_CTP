

## Description

This project contains a Python script that uses the Merge Sort algorithm to sort student records based on their marks in descending order. After sorting, the system processes the data to identify and display the students who are eligible for a scholarship based on a defined cutoff score.

## Algorithm

The core logic of the system follows this step-by-step algorithm:

1. **Start**
2. **Get Data:** Retrieve the initial list of students and their corresponding marks.
3. **Sort Data (Merge Sort):** Apply the merge sort algorithm to sort the students in descending order based on their marks.
4. **Display Sorted Records:** Print the sorted list of students and their marks.
5. **Set Cutoff:** Define the minimum marks required for a scholarship (e.g., cutoff = 85).
6. **Check Eligibility:** Iterate through the sorted list to find students whose marks are greater than or equal to the cutoff.
7. **Display Eligible Students:** Print the final list of students who qualify for the scholarship.
